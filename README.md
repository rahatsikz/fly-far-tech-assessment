### Fly Far Tech - Assessment

### Production Link

Vercel: [https://fly-far-tech-assessment.vercel.app](https://fly-far-tech-assessment.vercel.app)

### Used Technology

- Next.js (v.15.3)
- React.js (v.19)
- Material UI
- TypeScript

### For Running Locally

First, Clone the Repository

```bash
git clone https://github.com/rahatsikz/fly-far-tech-assessment.git
```

Then, install all dependencies

```bash
bun install
```

Finally, run the development server:

```bash
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the output.
